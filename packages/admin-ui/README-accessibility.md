# Accessibility target

WCAG 2.2 AA is the design target for the LORB Administration Workspace. Keyboard access, visible
focus, semantic landmarks (including a level-one heading on every page), and a skip-to-content link
are implemented for human review. `@axe-core/playwright` runs against the Overview page as part of
the happy-path end-to-end test as a design-target check, not a conformance claim. This document does
not claim conformance or certification; those are human review outcomes.
