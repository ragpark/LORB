# LORB

A PRIZM-like capability for launching learning objects.

## Development approach

LORB uses spec-driven development: the approved specification is the source of
truth for design, implementation, and verification. Start with the
[specification workflow](docs/specs/README.md), then use the repository's
[contribution guide](CONTRIBUTING.md) when preparing a change.

Each feature lives in `docs/specs/<feature-name>/`. The YAML contract and design
document supplied for a feature sit beside the planning, task, decision, and
verification records created from the templates in `docs/templates/`.
